# Dot Launcher — как поставить на телефон

Это главный экран для Android (подходит для Nothing Phone (1)):
- свайп вправо (или влево — меняется в настройках) открывает все приложения по алфавиту с буквами над группами;
- список изгибается дугой при прокрутке, алфавит сбоку;
- размер иконок, текста, часов, цвета, форма иконок — в настройках;
- ваши обои остаются — лаунчер показывает те, что уже стоят на телефоне.

Управление на телефоне:
- **Удерживать пустое место на главном** → настройки.
- **Удерживать приложение** → добавить на главный экран / убрать / удалить.
- **Кнопка «Назад»** закрывает меню.

## Шаг 1. Собрать APK (один раз, на компьютере)

1. Скачайте и установите **Android Studio** (бесплатно): https://developer.android.com/studio
2. Распакуйте архив `DotLauncher.zip` в любую папку.
3. В Android Studio: **File → Open** → выберите папку `DotLauncher`. Подождите, пока внизу закончится загрузка (первый раз 5–15 минут, нужен интернет).
4. Меню **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
5. Когда появится «APK(s) generated», нажмите **locate** — откроется папка с файлом `app-debug.apk`.

## Шаг 2. Поставить на телефон

1. Перекиньте `app-debug.apk` на телефон (кабелем, Telegram «Избранное», Google Диск — как удобно).
2. Откройте файл на телефоне. Если спросит — разрешите «Установку из этого источника».
3. Нажмите **Установить**.
4. Нажмите кнопку «Домой» → выберите **Dot Launcher** → **Всегда**.
   Если не спросило: Настройки → Приложения → Приложения по умолчанию → Главный экран → Dot Launcher.

## Как вернуть обычный экран Nothing

Настройки → Приложения → Приложения по умолчанию → Главный экран → Nothing Launcher.
(Или в настройках Dot Launcher кнопка «Выбрать другой главный экран».)

## Без компьютера (через GitHub)

В проекте уже есть файл `.github/workflows/build.yml`. Если загрузить папку в свой репозиторий на github.com,
GitHub сам соберёт APK: вкладка **Actions → Build APK → Artifacts → DotLauncher-apk**.

## Если что-то пошло не так

- Шрифт часов «из точек» подгружается из интернета; без сети будет обычный шрифт.
- Если после установки нового приложения его нет в списке — вернитесь на главный экран, список обновится.
